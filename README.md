# BudgetBuddy - Salary Budgeting & Goal Tracker

BudgetBuddy is a modern, responsive salary budgeting and automated savings goal tracking application built with React 19, TypeScript, Vite, and Tailwind CSS.

---

## 🚀 Quick Start & Local Execution

### 1. Prerequisites
- **Node.js**: v18.0.0 or later ([Download Node.js](https://nodejs.org))
- **Git**

### 2. Setup & Run
```bash
# 1. Clone your repository
git clone <YOUR_REPO_URL>
cd <YOUR_REPO_NAME>

# 2. Copy environment file
cp .env.example .env

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🧪 Testing & Building

```bash
# Type check & lint
npm run lint

# Production build
npm run build

# Preview production build locally
npm run preview
```
